# Python Retail Sales & Customer Analytics

## Project Overview

This project analyzes retail sales and customer data using Python to identify patterns in revenue, products, customers, countries, and time periods.

The analysis includes data cleaning, exploratory data analysis (EDA), data visualization, statistical testing, correlation analysis, and regression analysis.

The goal is to use statistical and analytical methods to understand sales patterns and customer behavior and present the findings clearly.

## Dataset

The dataset contains retail sales and customer transaction information, including variables related to products, customers, countries, quantities, revenue, and transaction dates.

The dataset was analyzed using Python to identify sales trends, customer patterns, product performance, and geographical differences.

## Project Objectives

- Clean and prepare the retail sales data for analysis.
- Explore sales and revenue patterns using EDA.
- Analyze product and customer-level performance.
- Examine revenue patterns across countries and time periods.
- Compare revenue between weekdays and weekends.
- Identify relationships between numerical variables using correlation analysis.
- Apply statistical tests to investigate differences and associations in the data.
- Build a simple regression model to examine the relationship between quantity and revenue.
- Summarize the key findings from the analysis.

## Analysis Performed

### 1. Data Cleaning
- Checked the dataset structure and data types.
- Checked for missing values and duplicate records.
- Created and prepared variables required for analysis.
- Prepared date-related variables for time-based analysis.

### 2. Exploratory Data Analysis
- Analyzed overall revenue and quantity.
- Examined product-level performance.
- Analyzed customer-level patterns.
- Compared revenue across countries.
- Examined revenue patterns over time.
- Analyzed weekday versus weekend revenue.

### 3. Statistical Analysis
- Correlation analysis
- Independent samples t-test
- ANOVA
- Chi-square test
- Simple linear regression

### 4. Data Visualization
- Created charts to understand distributions, trends, comparisons, and relationships within the data.

## Key Findings

- Revenue showed a positive but weak correlation with quantity (r ≈ 0.156).
- The weekday versus weekend revenue comparison showed a statistically significant difference (p < 0.05).
- ANOVA showed a statistically significant difference between the revenue groups analyzed (F = 27.3953, p < 0.05).
- The chi-square test showed a statistically significant association between country and year (χ² = 1506.1454, df = 39, p < 0.05).
- The simple linear regression model had an R² of approximately 0.0244, indicating that quantity alone explained a small proportion of the variation in revenue.

## How to Run the Project

1. Download or clone this repository.
2. Install Python and the required libraries listed in `requirements.txt`.
3. Make sure `online retail.xlsx` is placed inside the `data` folder.
4. Open `retail_sales_analysis.py` in Spyder or another Python IDE.
5. Run the script.
6. The analysis results and visualizations will be displayed/generated by the script.

## Data Source

Data Source

The dataset used in this project is the Online Retail II dataset from the UCI Machine Learning Repository.

It contains transaction data from a UK-based online retail business, covering transactions from December 2010 to December 2011.

Source: "UCI Machine Learning Repository — Online Retail II" (https://archive.ics.uci.edu/dataset/352/online%2Bretail)

Dataset citation: Chen, D. (2015). Online Retail [Dataset]. UCI Machine Learning Repository. DOI: 10.24432/C5BW33.
